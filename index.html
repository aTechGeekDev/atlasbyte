ATLAS BYTE

The world, one weird map at a time. Atlas Byte is a YouTube channel of short, fact-checked videos about maps, borders, time zones, population and geography myths. Every map and graphic is made by us from public-domain Natural Earth data.

About the Atlas Byte Uploader app

"Atlas Byte Uploader" is a private tool used only by the owner of the Atlas Byte YouTube channel. It uses the YouTube Data API and YouTube Analytics API to:

  • upload and schedule the channel's own Shorts, set titles, descriptions, thumbnails and playlists;
  • read the channel's own video statistics (views, watch time, subscribers gained) to learn which videos perform best.

It is not offered to the public and only accesses YouTube channels its owner authorizes. Read the privacy policy.
