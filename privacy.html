Privacy Policy

Last updated: 19 November 2026

This policy covers "Atlas Byte Uploader", a private tool operated by the owner of the Atlas Byte YouTube channel to manage that channel.

What the app accesses

When the channel owner signs in with Google, the app requests access to the YouTube Data API and the YouTube Analytics API for the channel(s) the owner chooses. It uses that access only to upload, schedule and edit the channel's own videos (titles, descriptions, thumbnails, playlists) and to read the channel's own performance statistics.

What is stored

  • OAuth access/refresh tokens, stored only on the owner's own computer or server, with owner-only file permissions.
  • Video IDs, upload times and aggregate statistics (views, watch time, subscribers gained) for the channel's own videos.

The app does not collect, store or process data about viewers or other YouTube users, and it does not use cookies or tracking on this website.

Sharing

No data is sold, shared or transferred to third parties. Data is used only to operate the channel.

YouTube API Services

The app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google Account → Third-party connections. Stored tokens and statistics are deleted by the owner when the tool is retired, or on request.

Contact

Questions about this policy: contact Atlas Byte through the channel's YouTube page (About → contact).
